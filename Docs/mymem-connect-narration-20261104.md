# MyMem Connectで表紙原稿を渡す（2026-11-04）

Ishizaka。MyMemOS資料1.0.1、PRO/Docs主版0.36.4を維持。日本語表紙のJSONを `public/narration/cover.ja.json` に収録し、ユーザー提供の13区分を改変しない。

対応拡張がある日本語表紙に、Connect操作枠内のapplication/jsonとして原稿を提示する。文字列の`<`をエスケープし、コードとして実行せず、本文・ポインター対象・資料画像・印刷/PDFへ混ぜない。英語ページへ日本語原稿を渡さない。

対応するPRO開発ビルドは、trusted clickで原稿を取得し、公開元・長さ・内容を検証した後、単回claimで起動元のサイドパネルへ渡す。受信時に「原稿を作って読み上げ」を選び、13区分を確認・編集できる。「説明開始」でこの原稿を再生成せずに使用する。現在のページ・本文・画像取得は改めて検証するため、JSONにある過去のpageId/imageStatusは取得許可・状態判定に使わない。原稿はパネル内の一時状態で、MyMemのDB/保存形式/バックアップや新しいブラウザー永続キーを追加しない。

OSのNext.js本番ビルド、関連PRO 8ファイル150テスト・TypeScript・online-setupビルドが成功。実Webビルド/空Chrome/実Connectクリック/実サイドパネルで、音声が未接続でも13区分を受け取ること、自動選択、接続だけでは送信0、「説明開始」の1回だけで提供原稿を送ること、再読込で再実行しないことを確認。送信境界はローカル受領確認に置き換え、実AI・アカウント・マイクを使わない。

公開と公開URLの最終確認結果は、反映後に追記する。
