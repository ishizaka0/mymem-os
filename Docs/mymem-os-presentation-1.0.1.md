## mymem OSプレゼン資料が伝える考え方

mymem OSプレゼン資料1.0.1の表紙メッセージは **「思考の手順を、すべての人に。」** です。mymemを「人とAIのあいだをつなぐ仕組み」として説明し、個人の経験や判断に閉じた暗黙知を、再利用できる思考の構造・手順へ変えていく考え方を示します。

資料で重視するのは、思考の再現性、手順によって生まれる自由、他者が再利用できる知識・視点の共有です。Skill Networkは、個人・分身AI・他者のあいだで思考手順をつなぎ、創造につなげる構想として紹介します。

11ページ目では **「AIは『提案』するが、『確定』するのは常に人間」** と説明します。価値判断と最終決定の主体を人間に置き、AIは整理・比較・提案によって思考を補助するという設計思想です。

## 日本語版・英語版の表示方法

mymem OSプレゼン資料1.0.1は、URLで指定した言語を優先します。

- **日本語版**：https://os.mymem.net/?lang=ja
- **英語版**：https://os.mymem.net/?lang=en

`lang` に `ja` または `en` を指定すると、ブラウザーの言語設定にかかわらず、その言語で表示します。言語指定がない場合や未対応の値の場合は、ブラウザーの言語設定を使います。ブラウザー言語が `ja` で始まる場合は日本語、それ以外は英語です。

表示言語の選択は、全14ページの本文・操作案内・PDF保存時の内容に共通して反映します。日本語版と英語版の確認に、ブラウザー自体の言語設定を変更する必要はありません。

## ページの移動とPDF保存

mymem OSプレゼン資料1.0.1では、画面下の左右の矢印、各ページを選ぶ丸いボタン、キーボードの左右矢印キーで全14ページを移動します。右下に現在のページ番号を表示します。

PDF保存は、**右上のダウンロードアイコンからブラウザーの印刷ダイアログを開き、「PDFに保存」を選ぶ**操作です。表示中の1ページだけではなく、全14ページが印刷対象になります。画面で選んだ日本語・英語がPDFにも反映されます。

印刷用CSSの用紙指定は **A3横向き（420mm × 297mm）、余白0** です。スライド1枚がPDFの1ページになる構成です。最終的な保存先や印刷ダイアログの表示は、利用するブラウザーとOSによって異なります。

表紙左下の **「PDF出力について」** は、画面では1ページ目だけに表示します。2ページ目以降には表示しません。印刷・PDF保存時には、この操作案内を全ページで非表示にします。

資料版 **`v1.0.1`** は、表紙のダウンロードアイコンの真下に中央揃えで小さく表示します。版番号はPDFの表紙にも表示します。2ページ目以降には版番号を追加しません。

1.0.1のPDF保存は `window.print()` と印刷用CSSによるものです。`Docs/download_pdf.md` と `Docs/2_pdf_debug.md` にあるhtml2canvas・jsPDFの記述は過去の設計検討であり、ここで説明する1.0.1の公開実装には採用していません。
